01 — THE PROBLEM

Same input. Different behavior.

A successful execution does not guarantee equivalent behavior across environments.

01

Runtime differences

Runtime versions and internationalization data can influence how applications interpret and sort text.

NODE.JS
02

Database differences

Database collation settings and providers can produce ordering behavior that differs from application code.

POSTGRESQL
03

Invisible inconsistencies

Version information alone cannot establish whether two systems actually produce equivalent results.

OBSERVED BEHAVIOR
THE PRINCIPLE
“Versions are metadata. Observed behavior is evidence.”

Materna focuses on what systems actually produce, not merely what their version information suggests.

02 — THE APPROACH

Observe first. Compare with evidence.

Materna establishes a repeatable structure for collecting and comparing behavioral observations.

01

Shared test contract

Use a defined probe and an immutable corpus so observations have a consistent foundation.

02

Environment observations

Collect runtime and environment metadata alongside actual results.

03

Deterministic fingerprints

Generate SHA-256 hashes from serialized observed results.

04

Explicit comparison

Distinguish matching observations, behavioral differences and insufficient evidence.

03 — DEVELOPER WORKFLOW

A small foundation. A clear purpose.

The current implementation provides a Node.js probe, a PostgreSQL adapter and a programmatic comparison API.

STEP 01 NODE.JS

Collect an observation

Run the existing Node.js collation probe.

TERMINAL 01 
npm run probe:node
STEP 02 POSTGRESQL

Collect another observation

Run the PostgreSQL adapter when a database and required dependencies are available.

TERMINAL 02 
npm run probe:postgres
STEP 03 PROGRAMMATIC API

Compare observations

Use the existing comparison API with two previously collected observations.

JAVASCRIPT 03 
import {
  compareObservations
} from "materna";

const result = compareObservations(
  nodeObservation,
  postgresObservation
);

console.log(result.status);
i

Implementation note: The CLI does execute this workflow: node src/cli.js compare --left node.json --right pg.json. The API above is the same comparison, callable from your own code. Exit codes: 0 PASS, 1 DIFFERENCE, 2 INCONCLUSIVE, 3 ERROR.

05 — CURRENT SCOPE

Built on evidence. Honest about limits.

Materna is an early engineering foundation. Its current capabilities should not be confused with a production-ready compatibility platform.
