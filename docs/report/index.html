Next steps

    
Materna observes behavior once. The tools below answer the next questions — under load, over time, and under real traffic. Materna does not bundle them.

    

      

        
Load testing this endpoint?

        
autocannon · Node-native, zero config

        
npx autocannon -c 100 -d 30 http://localhost:3000

      

      

        
Sustained PostgreSQL benchmark?

        
pgbench · Built into PostgreSQL

        
pgbench -c 50 -T 60 -f probe.sql materna_db

      

      

        
Memory profiling over time?

        
Node Inspector · Built into Node.js

        
node --inspect src/cli.js probe:node

      

      

        
Why is this query slow?

        
EXPLAIN ANALYZE · Built into PostgreSQL

        
EXPLAIN (ANALYZE, BUFFERS) SELECT ...

      

    

    
Materna will not run these for you. It shows you where to look next — then steps aside.
